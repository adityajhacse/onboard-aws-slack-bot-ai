🚀 QUICK START
═══════════════════════════════════════════════════════════════════════

1. Configure Terraform:
   cd terraform
   cp terraform.tfvars.example terraform.tfvars
   # Edit with your credentials

2. Deploy infrastructure:
   terraform init
   terraform apply

3. Get API endpoint:
   terraform output api_gateway_url

4. Update Slack app:
   export API_GATEWAY_ENDPOINT="<url from step 3>"
   cd ../src && python main_with_api_gateway.py

5. Test via Slack:
   /aws-det-poc → Fill form → Submit
   Result: "Workflow started\! Execution ID: abc123"

6. Check status in DynamoDB:
   aws dynamodb get-item \
     --table-name det-onboarding-prod-executions \
     --key '{"execution_id": {"S": "abc123"}}'
